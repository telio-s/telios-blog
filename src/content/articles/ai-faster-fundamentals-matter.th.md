เครื่องมือ AI ทำให้การสร้างโค้ดทำได้เร็วขึ้น เรื่องนี้มีประโยชน์ แต่ความเร็วอย่างเดียวไม่ได้รับประกันว่าระบบ Software จะดี

ส่วนที่ยากของ Software มักไม่ใช่การพิมพ์โค้ด แต่คือการเข้าใจปัญหา เลือกขอบเขตที่เหมาะสม จัดการ state ออกแบบ data flow รับมือ error ทดสอบพฤติกรรม และตัดสินใจว่าอะไรยังไม่ควรถูกสร้าง

AI ช่วยสร้างทางเลือก ร่างโค้ด และอธิบาย API ที่ไม่คุ้นเคยได้ แต่ยังต้องมีคนเข้าใจว่าผลลัพธ์นั้นเหมาะกับผลิตภัณฑ์ ข้อจำกัด และต้นทุนระยะยาวในการดูแลระบบหรือไม่

เรื่องนี้สำคัญมากสำหรับธุรกิจที่ทำงานกับทีมภายนอก เดโมที่ทำเร็วอาจดูน่าประทับใจ แต่ซ่อน requirement ที่ไม่ชัด data model ที่อ่อน หรือ edge case ที่ยังไม่ถูกคิดไว้

คำถามที่มีประโยชน์ไม่ใช่แค่ "สร้างได้เร็วขึ้นไหม" แต่คือ "เรากำลังสร้างสิ่งที่ถูกต้อง ในแบบที่ธุรกิจพึ่งพาได้หรือไม่"
