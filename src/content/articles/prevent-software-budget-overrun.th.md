วันนี้มาแชร์ 3 เทคนิคสั้นๆ ที่ทำให้งบไม่บานปลายจากการจ้างคนทำ Software

ก่อนจ้างหรือติดต่อ Developer ให้ลองเขียน Requirement ออกมาก่อน

เพราะการเขียนสิ่งที่เราอยากได้ ช่วยให้เราเข้าใจเป้าหมายและเห็นภาพ Software นั้นชัดขึ้น

มีหลายครั้งที่เจ้าของธุรกิจอยากได้ Software แต่ยังตอบคำถามตัวเองไม่ได้ว่า Software นั้นช่วยแก้ปัญหาอะไร หรือมี Business Rule และกฎเกณฑ์ในการแสดงผลอย่างไร

3 สิ่งที่อยากให้ลองเขียนมีดังนี้

## 1. ใครคือคนใช้ Software

บอกให้ชัดเจนว่าคนใช้งาน Software คือใคร และ Software นั้นทำอะไรได้บ้าง

ลองเขียน Feature ที่อยากให้ Software มีออกมา เช่น ระบบการจอง ระบบจ่ายเงิน หรือลูกค้าสามารถจองและจ่ายเงินหลังจองได้ทันที

## 2. เขียน Flow ปกติของการใช้งานระบบ

จากข้อก่อนหน้าที่เราเขียน Feature ออกมาเป็นหัวข้อ หรืออธิบายว่า Software ทำอะไรได้บ้าง ให้ลองนำมาเรียบเรียงเป็นลำดับเหตุการณ์

เช่น

กดจอง → เลือกวันที่ → เลือกเวลา → ระบุจำนวนคน → ระบบแสดงโต๊ะที่ว่าง → เลือกโต๊ะ → ยืนยันการจอง → แสดง QR Code จ่ายเงิน → แสดงหน้าจ่ายเงินสำเร็จ

## 3. มีเงื่อนไขอะไรบ้างที่ระบบต้องรู้

ลองอ่าน Flow ที่เราเขียนเสร็จ แล้วระบุเงื่อนไขหรือ Business Rule ที่สอดแทรกอยู่ใน Flow

เช่น

- การเลือกวันที่ สามารถเลือกล่วงหน้าได้ไม่เกิน 30 วัน
- มาสายเกิน 15 นาที ระบบยกเลิกอัตโนมัติ

เท่านี้ก็สามารถเพิ่มความชัดเจน และเพิ่มความเข้าใจที่ตรงกันให้ทั้ง Developer และเจ้าของธุรกิจได้แล้ว
